# 微信小程序 · 扫雷游戏

这是一个将经典扫雷玩法移植到微信小程序平台的项目。项目保留扫雷核心机制，并针对移动端交互进行了适配，支持首击保护、长按插旗、双击快速开等特性，同时提供玩法说明与动态状态栏，便于玩家上手与复盘。

## 功能概览
- **固定雷数 + 首击保护**：首次点击才布雷，并避开首击格九宫格，默认 10 枚地雷，可在 `pages/index/index.js` 中调整。
- **基本操作**：
  - 单击翻开格子，自动扩散空白区域与数字。
  - 长按在空白 → 🚩 → ❓ 之间循环；旗帜影响剩余雷数，问号仅作提示。
  - 双击已翻开数字格，当周围旗帜数满足该数字时自动翻开剩余邻格，误标会直接判负。
- **状态管理**：顶部 HUD 实时显示剩余雷数、计时器、状态提示，可随时重新开始。
- **结算表现**：失败时揭示所有雷并标记错旗，胜利时自动展示剩余雷，终止计时，防止后续操作。
- **玩法说明面板**：棋盘下方罗列关键规则，帮助用户快速理解操作。

## 开发环境准备
1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 以“导入项目”的方式选择当前仓库目录，AppID 可使用测试号或体验号。
3. 启动模拟器后即可看到扫雷页面，无需额外构建脚本。

## 本地调试
- **尺寸/雷数调整**：在 `pages/index/index.js` 顶部修改 `DEFAULT_WIDTH`、`DEFAULT_HEIGHT`、`DEFAULT_MINES`，棋盘宽度会自动适配，仍保持首击安全。
- **问号开关**：`data.questionMarksEnabled` 为 `true` 时开启问号状态；如需禁用，可在 reset 或页面 `data` 中设为 `false`。
- **快速开间隔**：`DOUBLE_TAP_THRESHOLD` 控制双击识别的时间窗口（毫秒），可按个人习惯调整。

## 玩法说明（与 UI 同步）
- 单击翻开方块，首击保证不会遇雷。
- 长按在空白 → 🚩 → ❓ 间循环；旗帜会减少剩余雷数，问号仅作提示，仍可单击翻开。
- 双击已翻开的数字格，当周围旗帜数量等于该数字时，自动翻开剩余邻格；若旗帜不足或误标含雷格，会立即失败。
- 所有非雷格翻开即获胜；翻到雷或快速开误触雷会失败并显示所有雷与错旗。
- 计时在首次成功翻格后开始，胜利或失败时自动停止；可通过“重新开始”重置。

## 核心逻辑说明
- `utils/minesweeper.js`
  - `createEmptyBoard(rows, cols)`：初始化空棋盘。
  - `seedMines(board, mineCount, firstClick)`：首击后布雷并避开首击九宫格。
  - `revealCell(board, flags, row, col)`：递归翻开空白区域，返回爆炸与揭示数量。
  - `chordOpen(board, flags, row, col)`：用于快速开逻辑，依据旗帜数展开相邻格。
  - `revealMinesAndMarkMistakes(board, flags)`：失败或胜利时揭示雷并标记错旗。
- `pages/index/index.js`
  - 负责状态管理（棋盘、旗帜、计时、剩余雷数）、事件响应、胜负判定与 UI 数据拼装。
  - `composeDisplayGrid` 将底层棋盘状态映射到渲染层，区分隐藏/空白/数字/雷/错旗/爆炸等状态。

## 后续扩展建议
- **难度预设或自定义面板**：添加设置抽屉，供用户选择不同尺寸与雷数。
- **问号状态配置**：提供开关入口，让用户自定义是否启用问号。
- **快速开替代手势**：除了双击，可探索双指轻点等更符合移动端的交互。
- **声音与动画**：翻开、插旗、胜负时增加动效或音效反馈，提升沉浸感。
- **数据统计**：纪录最佳成绩、连胜次数等信息，增强可玩度。
